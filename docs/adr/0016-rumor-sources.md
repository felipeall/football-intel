# 16. Rumor sources (backlog)

Status: Deferred — 2026-10-12 (backlog, see ADR 1)

## Decision
Ingest from the Guardian Open Platform API (official, free key, full text), the BBC Sport gossip column RSS (credits original outlets), and Bluesky (official free API, journalist accounts). A small model extracts structured Rumors.

## Rejected
X/Twitter (API cost) and Reddit (restricted API).
