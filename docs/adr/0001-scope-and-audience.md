# 1. Scope and audience

Status: Accepted — 2026-10-11

## Context
Portfolio project for GitHub (felipeall). Prior work is data-engineering heavy (`football-data-platform` v1, `transfermarkt-api`). The new signal to show is AI engineering, backed by a credible data platform.

## Decision
- Audience: both AI/LLM engineering and data/platform engineering roles, weighted toward AI.
- Product core: AI Scout Agent is the MVP. Transfer Rumor Tracker is phase 2.
- Budget: ~8 hours/week, demoable MVP in ~6 weeks.

## Consequences
Scope must stay small enough to finish; v1 stalled as a WIP. Anything not on the MVP path is deferred to phase 2.
